# Banking System in C++

## Project Overview
This is a simple Banking System developed using C++. It allows users to manage different types of bank accounts and perform basic banking operations.

## Features
- Savings Account
- Checking Account
- Fixed Deposit Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Calculate Interest
- Display Account Information

## Concepts Used
- Class and Object
- Inheritance
- Polymorphism
- Encapsulation
- Constructor
- Virtual Functions

## Technologies Used
- C++
- VS Code
- GCC Compiler
